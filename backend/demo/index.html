CloudSched – Operating Systems demo

Real scheduling / resource / deadlock algorithms running in Python. A simulation: results are for the workload you enter, not a real OS or hypervisor. No database needed for this demo.

Workload
One job per line: pid,arrival,burst,priority[,deadline] — priority 1 = highest. Time in simulation units.
CPU scheduling
Compare all algorithms & recommend
Weights (normalised to sum 1; configurable). Deadline weight grows with the share of jobs that have deadlines.
Resource management (shared CPU / RAM / storage)
Jobs run concurrently while resources last; otherwise they wait. Resources are released exactly once; invariants are checked on every step. pid,arrival,burst,priority,cpu,ram_mb,storage_mb
Banker's Algorithm (deadlock avoidance)
Resource types A, B, C. Edit the state, then test a request. Outcomes: GRANTED (safe) · DEFERRED_UNSAFE · DEFERRED_UNAVAILABLE · INVALID (exceeds declared max). Models only these declared resources.
Starvation prevention – priority aging
Job L (priority 10, burst 1) arrives at t=0 together with a stream of 100 priority-1 jobs (burst 5, one every 5 units). Aging improves a waiting job by 1 priority level per interval.
